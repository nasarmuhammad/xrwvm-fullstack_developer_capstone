# Cars Dealership — Full-Stack Development Capstone

Cars Dealership is a full-stack automobile dealership review
application built for the IBM Full Stack Software Developer
Capstone Project.

## Project Overview

The application allows customers to browse dealerships across
the United States, filter dealers by state, view dealer details,
register and log in, read and post customer reviews, and analyze
review sentiment.

## Technology Stack

- Frontend: React, HTML, CSS, JavaScript
- Backend: Django, Python, Node.js, Express
- Databases: SQLite and MongoDB
- Sentiment Analysis: Python microservice
- Deployment: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions

## Features

- Dealership browsing and state filtering
- User authentication and registration
- Dealership reviews
- Car make and model management
- Review sentiment analysis
- Responsive About Us and Contact Us pages
